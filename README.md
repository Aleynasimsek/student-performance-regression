# 📈 Student Performance Regression Analysis

## 📌 Project Overview
This project explores the relationship between weekly study time and student exam performance. By building and comparing multiple regression models, the objective is to accurately predict exam scores based on study habits, showcasing the application of predictive analytics in educational data.

## 🚀 Technologies & Frameworks
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Data Visualization:** Matplotlib, Seaborn

## 🧠 Models Developed
Several regression techniques were implemented to capture the underlying patterns in the data:
* **Linear Regression:** To establish a baseline linear relationship.
* **Polynomial/Multiple Regression:** To capture potential complex trends between variables.
* **Random Forest Regressor:** Applied to handle non-linear relationships and compare against baseline models.

## 📊 Results & Evaluation
The models were evaluated using industry-standard metrics such as **Mean Squared Error (MSE)** and the **R² Score** to determine the goodness of fit. The **Random Forest Regressor** yielded the best predictive performance, successfully capturing the complex variance in exam scores with a high R² score and demonstrating its effectiveness over simple linear models.
